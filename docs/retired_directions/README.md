# Retired / Wrong-Direction Records

> Last updated: 2026-04-12
> Status: archive index

这个目录用于放置已经**不应再作为当前主线决策依据**的实验方向记录。

放入这里的文档通常满足至少一条：

- 后续证据已表明该方向不应继续作为 mainline
- 该方向的主叙事已被更晚的因果记录降级或推翻
- 该文档更适合保留为 negative evidence / archaeology，而不是 live plan
- 该文档仍有历史价值，但继续放在 `docs/train_design` 主层级会误导为“当前还在推进”

使用规则：

- 当前主线优先看 `docs/train_design/`
- 当前 posttrain 入口优先看 `docs/posttrain_pipeline.md`
- 如果要看 clean StepC / top7-family 证据，优先看 `docs/train_design/2026-04-12_top7_clean_stage6_stepc_causality_record.md`
- 这里的文档只用于：
  - 复盘错误方向
  - 查证哪些假设已被 falsify / retire
  - 避免未来重复投入同类路线

本目录当前收纳的主要家族：

- `replace_redesign_and_falsifier_family/`：universal-corrector / replace-redesign / adapter / factorized / closed-loop falsifier / sham-downgrade 整组归档
- `top7_old_boundary_transferability_family/`：legacy old-boundary `top3/top7` transferability、pre-framework memo、notail、distribution-pathology 等证据整组归档
- `legacy_upstream_handoff_control_family/`：`2026-03-19 ~ 2026-04-02` 的 upstream / handoff / control 历史设计与验证整组归档
- `retired_corrector_recovery_family/`：R0 / shape-axis / legacy recovery 退役 corrector 线整组归档
- `aux_shared_trunk_family/`：aux-family 最终未进入 mainline 的整组总结与明细记录
